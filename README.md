A simple Python program that generates a folder structure **(Tree's)** with .md or .txt files

## A simple app for a simple task!
Tired of constantly updating the folder structure in your README?
Then let me introduce Trees Gen, a super-lightweight app that formats your folder structure just right so you don’t have to do that tedious work.

## 🤓 Features
- Create the folder and file structure (Pretty obvious, right?)
- Avaliable Formats .txt or .md
- Select where you want to save it
- Funny status messages in the “Generate” tab
